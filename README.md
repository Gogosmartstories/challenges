# بيتنا مستدام.. وقطر تستحق

مبادرة التحديات الأسبوعية للأسرة
مدرسة هند بنت عتبة الإعدادية للبنات - قسم اللغة الإنجليزية

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية (بطاقات التحديات) وصفحة كل تحدٍّ (`/day/1` إلى `/day/4`) |
| `config.js` | رابط السكريبت، وبيانات التحديات وتواريخها |
| `vercel.json` | إعدادات Vercel وروابط صفحات الأيام |
| `Code.gs` | كود Google Apps Script (يُلصق في script.google.com، وليس جزءًا من الموقع) |

كل تحدٍّ يستقبل المشاركات 24 ساعة فقط في يومه بتوقيت قطر.
تُحفظ مشاركات كل يوم في مجلده (تحدي1 إلى تحدي5)، وتُسجَّل في جدول «سجل المشاركات» داخل المجلد نفسه.
